# Airbnb Hotel Booking Analysis

This project focuses on analyzing Airbnb hotel booking data to identify useful patterns and insights related to listings, pricing, room types, neighbourhoods, and availability.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Overview

The project includes data cleaning, exploratory data analysis (EDA), and data visualization to understand trends and relationships within the Airbnb dataset.

## SQL Analysis

To strengthen the analysis, the same dataset was loaded into a local SQLite database and explored using SQL. Queries in `sql_queries.sql` cover filtering (WHERE), sorting (ORDER BY), aggregation (GROUP BY, COUNT, AVG), DISTINCT values, a CTE for group-level comparison, and a window function (RANK) to rank listings within each neighbourhood group.

**Tools:** SQLite, DB Browser for SQLite

## Dataset

The dataset used in this project is the **Airbnb Open Data** dataset.
You can download the dataset from Kaggle:
