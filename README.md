# Airbnb Hotel Booking Analysis

This project focuses on analyzing Airbnb hotel booking data to identify useful patterns and insights related to listings, pricing, room types, neighbourhoods, and availability.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Overview

The project includes data cleaning, exploratory data analysis (EDA), and data visualization to understand trends and relationships within the Airbnb dataset.

## Dataset

The dataset used in this project is the **Airbnb Open Data** dataset.
You can download the dataset from Kaggle:

[Download Airbnb Open Data Dataset](https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata)
